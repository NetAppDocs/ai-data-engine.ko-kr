= AI Data Engine에서 정책 생성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
반복적으로 발생하는 데이터 상태를 수동으로 조사하지 않고 모니터링하려면 정책을 생성하십시오. 예를 들어, 데이터 거버넌스 관리자는 "large stale files" 정책을 저장하여 스캔 주기 전반에 걸쳐 해당 파일 그룹을 추적하고 영향을 받는 파일 수가 변경될 때 이메일 업데이트를 받을 수 있습니다.



[[about-policies]]
== 정책에 관하여

정책은 조사에서 정의한 필터 기준을 재사용 가능한 규칙으로 저장합니다.  AI Data Engine은 매 스캔 주기 후 메타데이터 카탈로그에 대해 각 정책을 평가합니다.  언제든지 정책을 열어 현재 일치하는 결과 집합을 확인할 수 있습니다.  삭제 작업을 연결하면 AI Data Engine은 매 스캔 주기 후 일치하는 파일을 제거합니다.  이메일 알림을 연결하면 AI Data Engine은 영향을 받는 파일 수가 변경될 때 업데이트를 보냅니다.



[[choose-a-policy-action]]
== 정책 작업을 선택합니다

정책은 선택적 작업이 첨부된 저장된 필터 세트입니다.

* *모니터링 전용(조치 없음)*: 조치 없이 시간 경과에 따른 일치 그룹화를 추적합니다. 자동 대응을 실행하지 않고 가시성만 확인하고 싶을 때 사용하십시오.
* *이메일 알림 전송*: 일치하는 파일 개수가 변경될 때 사용자에게 이메일로 알림을 보냅니다.
* *영구 삭제*: 각 스캔 주기 후 추가 확인 없이 일치하는 모든 파일을 자동으로 영구 삭제합니다. 이 작업은 되돌릴 수 없습니다. 이 작업을 적용하기 전에 필터 기준이 정확한지, 그리고 식별된 파일을 삭제할 권한이 있는지 확인하십시오.




[[create-a-policy-from-investigation]]
== 조사에서 정책 만들기

.시작하기 전에
* 삭제 또는 이메일 알림 작업을 연결하려면 _AI Data Engine administrator_ 역할이 있어야 합니다. _AI Data Engine viewer_ 역할은 모니터링 전용 정책만 생성할 수 있습니다.


.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *조사*로 이동합니다.
. 정책 적용 대상이 될 파일을 식별하는 하나 이상의 필터를 적용합니다.
+
예를 들어, *파일 형식* = .vmdk이고 *마지막 접속 시간* > 365일입니다.

+
결과표를 검토하여 필터 설정이 의도한 데이터 그룹화를 제대로 반영하는지 확인하십시오.

. 필터 작업 표시줄에서 *정책 생성*을 선택합니다.
. 정책 이름을 입력합니다.
. 선택적으로 *설명*을 입력할 수 있습니다(최대 500자).
. 필터 기준 표현식(예:  `last_access_time <= 3 Years AND file_size >= 5GiB`)을 검토하여 선택 사항을 제대로 반영하는지 확인하십시오.
. 작업을 연결하려면 *작업*에서 다음 중 하나를 선택하십시오.
+
** *Monitor only (no action)* (기본값): 정책은 모니터링만 하는 조건으로 저장됩니다.
** *이메일 알림 보내기*: 지정한 수신자에게 이메일 알림을 보냅니다.
** *영구 삭제*: 추가 입력은 필요하지 않습니다.
+

CAUTION: '영구 삭제' 작업은 매 스캔 주기 후 이 정책과 일치하는 모든 파일을 자동으로 영구 삭제합니다. 저장하기 전에 필터 기준을 확인하고 해당 파일을 삭제할 권한이 있는지 확인하십시오.



. *생성*을 선택합니다.


.결과
정책이 저장되어 link:manage-policies.html["정책"] 페이지에 표시됩니다. 작업을 연결한 경우 AI Data Engine은 정책 기준과 일치하는 파일에 해당 작업을 적용합니다.



[[example-identify-cold-archive-files]]
== 예시: 콜드 아카이브 파일 식별

다음 예시는 1년 이상 접근 기록이 없는 파일이 감지될 경우 이메일 알림을 보내는 정책을 생성합니다.

. 조사 시 다음 필터를 적용하세요.
+
** *최근 접속 시간* > 365일


. *정책 생성*을 선택합니다.
. 정책 이름을 입력하세요: *Cold Files — Unaccessed 1 Year*.
. *이메일 알림 보내기* 작업을 선택하고 수신자 이메일 주소를 입력합니다.
. *생성*을 선택합니다.
