= AI Data Engine 배포에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine을 단일 VM 설치인 AIDE Lite로 배포하십시오. 대규모 환경에서 Kubernetes 기반의 고가용성이 필요한 경우 AIDE Enterprise를 대신 배포할 수 있습니다.



[[aide-lite]]
== AIDE Lite

AIDE Lite는 단일 Linux VM에 설치됩니다. 설치 프로그램이 k3s를 자동으로 프로비저닝하므로 Kubernetes 전문 지식이 필요하지 않습니다.

AIDE Lite는 소형, 중형, 대형의 세 가지 크기로 제공되며, 각각 약 2억, 10억, 30억 개의 파일을 처리할 수 있는 환경을 지원합니다. 전체 VM 크기 및 운영 체제 요구 사항은 link:aide-requirements.html["AIDE 요구 사항"]을 참조하십시오. 이러한 크기는 권장 기준이며, 절대적인 한계는 아닙니다. 크기 조정을 결정하는 요소 및 추가 확장 방법은 link:aide-requirements.html#flexible-sizing-lite["유연한 사이즈 가이드라인"]를 참조하십시오.



[[aide-enterprise]]
== AIDE Enterprise

고가용성, 내결함성, 롤링 업그레이드 또는 AIDE Lite의 최대 용량을 초과하는 수평 확장이 필요한 환경에는 AIDE Enterprise를 배포하십시오. AIDE Enterprise는 고객이 프로비저닝하고 관리하는 RKE2 클러스터에 멀티 노드 Kubernetes 클러스터로 배포됩니다.

AIDE Enterprise는 최대 약 10억, 30억, 60억 개의 파일을 처리할 수 있는 환경에 맞춰 소형, 중형, 대형의 세 가지 크기로 제공됩니다. 전체 노드 크기 및 클러스터 요구 사항은 link:aide-requirements.html["AIDE 요구 사항"]을 참조하십시오. 이러한 크기는 권장 기준이며, 엄격한 제한 사항은 아닙니다. 60억 개 이상의 파일을 처리하는 환경은 수평 확장을 통해 지원됩니다. 자세한 내용은 link:aide-requirements.html#flexible-sizing-enterprise["유연한 사이즈 가이드라인"]을 참조하십시오.



[[deployment-process]]
== 배포 프로세스


NOTE: AI Data Engine은 NetApp Console에서 비공개 미리 보기로 제공됩니다. AI Data Engine을 배포할 수 있도록 액세스를 요청하려면 NetApp 담당자에게 문의하십시오.

NetApp Console은 AI Data Engine의 인프라를 프로비저닝하지 않습니다. 요구 사항을 충족하는 Linux 머신 또는 클러스터를 준비한 다음, NetApp Console에서 미리 생성된 설치 명령을 복사하여 대상 호스트에서 실행합니다. 이 명령은 런타임을 부트스트랩하고 AI Data Engine 스택을 자동으로 배포합니다. 설치 과정에서 설치 프로그램은 설치를 진행하기 전에 대상 호스트의 IP 주소와 사용자 ID를 확인하라는 메시지를 표시합니다.

AIDE Lite 설치는 일반적으로 45분 이내에 완료됩니다. AIDE Enterprise 설치는 일반적으로 30분 이내에 완료됩니다. 설치 프로그램에는 구성 요소 시작 중 발생하는 일시적인 문제를 처리하기 위한 시간 초과 및 재시도 기능이 내장되어 있습니다.



[[deployment-mode-reference]]
== 배포 모드 참조

[cols="1h,2,2"]
|===
|  | AIDE Lite | AIDE Enterprise 


| 배포 모델 | 단일 Linux VM | 다중 노드 Kubernetes 클러스터(고객 제공 RKE2) 


| 스캔 속도 | 파일 크기에 따라 하루 5천만 개에서 10억 개까지 다양합니다. | 파일 크기에 따라 하루 2억 5천만~20억 개 파일 


| 최대 파일 수(대용량) | 약 30억 | 약 60억 
|===
