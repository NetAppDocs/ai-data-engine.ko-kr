= AI Data Engine 배포에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine(AIDE)을 AIDE 단일 노드 배포로 배포하십시오. 이 경우 설치 프로그램이 사용자가 제공하는 단일 Linux VM에 모든 것을 설정합니다. 환경에서 대규모로 Kubernetes 기반 고가용성이 필요한 경우, 사용자가 제공하는 Kubernetes 클러스터에 AIDE 다중 노드 배포를 배포할 수 있습니다.



[[aide-single-node-deployment]]
== AIDE 단일 노드 배포

AIDE 단일 노드 배포는 사용자가 제공하는 단일 Linux VM에 설치됩니다. 설치 프로그램은 k3s, Kubernetes 런타임, 그리고 AI Data Engine에 필요한 지원 툴 및 호스트 구성을 포함하여 그 외 모든 것을 자동으로 프로비저닝합니다. Kubernetes를 설치하거나 관리할 필요가 없으며, Kubernetes 전문 지식도 필요하지 않습니다.

AIDE 단일 노드 배포는 소형, 중형, 대형의 세 가지 크기로 제공되며, 각각 최대 약 2억 개, 10억 개, 30억 개의 파일이 있는 환경을 지원합니다. 전체 VM 크기 조정 및 OS 요구 사항은 link:aide-requirements.html["AIDE 요구 사항"]을(를) 참조하십시오. 이러한 크기는 권장 기준이며 절대적인 제한이 아닙니다. 크기 조정을 결정하는 요인과 크기를 초과할 경우 수행할 작업에 대해서는 link:aide-requirements.html#flexible-sizing-single-node["유연한 사이즈 가이드라인"]을(를) 참조하십시오.



[[aide-multi-node-deployment]]
== AIDE 다중 노드 배포

환경에 고가용성, 내결함성, 롤링 업그레이드 또는 최대 단일 노드 배포 크기를 초과하는 용량이 필요한 경우 AIDE 멀티 노드 배포를 배포하십시오. AIDE 멀티 노드 배포는 기존 Kubernetes 클러스터에 배포됩니다. 자체 Kubernetes 클러스터(RKE2, OpenShift 또는 AKS)를 준비해야 합니다. 클러스터를 직접 프로비저닝하고 관리해야 하며, 다른 워크로드와 공유하거나 AI Data Engine 전용으로 사용할 수 있습니다. 설치 프로그램은 클러스터를 생성하거나 관리하지 않습니다. 설치 프로그램을 실행하는 시스템은 경량 관리 호스트이며 AI Data Engine 워크로드를 실행하지 않습니다.

AIDE 멀티노드 배포는 소형, 중형, 대형의 세 가지 크기로 제공되며, 각각 최대 약 10억, 30억, 60억 개의 파일이 있는 환경을 지원합니다. 전체 노드 크기 조정 및 클러스터 요구 사항은 link:aide-requirements.html["AIDE 요구 사항"]을(를) 참조하십시오. 이러한 크기는 권장 기준이며 엄격한 제한은 아닙니다. 60억 개 이상의 파일이 있는 환경은 NetApp을 통한 맞춤형 크기 조정이 필요합니다. 자세한 내용은 link:aide-requirements.html#flexible-sizing-multi-node["유연한 사이즈 가이드라인"]을(를) 참조하십시오.



[[compare-deployment-types]]
== 배포 유형 비교

[cols="1h,2,2"]
|===
|  | AIDE 단일 노드 배포 | AIDE 다중 노드 배포 


| 배포 유형 | 사용자가 제공하는 단일 Linux VM입니다. 설치 프로그램이 k3s를 자동으로 프로비저닝합니다. | 다중 노드 Kubernetes 클러스터. RKE2, OpenShift 또는 AKS 클러스터는 직접 준비하셔야 합니다. 


| 노드 | Linux VM 1개 | 3개에서 9개 노드(소형부터 대형까지) 


| 스캔 속도 | 하루 5천만 개에서 10억 개의 파일, 크기에 따라 다양합니다. | 하루 2억 5천만 개에서 20억 개의 파일, 크기에 따라 다릅니다. 


| 대략적인 파일 크기 (작은 파일부터 큰 파일 순) | 2억에서 30억 | 10억에서 60억 


| 컴퓨팅 | 16~96개의 vCPU, 64~192GB RAM | 노드당 32~64개의 vCPU, 128~256GB RAM 


| 스토리지 | 500GB~6TB SSD 블록 스토리지, 8,000~16,000 IOPS, 1,000~2,000MB/s 처리량 | 총 클러스터 용량 4~24TB, 노드당 IOPS 8,000~16,000, 노드당 처리량 1,000~2,000MB/s 


| 네트워크 | 1 GbE (대형에는 10 GbE 권장) | 1~10GbE 


| 고가용성 | 지원되지 않음 | 노드 전반에 걸쳐 지원됩니다 


| 언제 선택해야 하는지 | 사이트가 하나이고, 빠른 시작을 원하며, 고가용성이 필요하지 않습니다 | 운영 규모 또는 HA는 필수 요건입니다 
|===


[[deployment-process]]
== 배포 프로세스

NetApp Console에서 직접 AI Data Engine을 배포할 수 있습니다. *AI 데이터 허브 > AI Data Engine*으로 이동하여 AI Data Engine을 배포합니다. 마법사를 사용하여 배포 유형을 선택한 다음, link:aide-requirements.html["AIDE 요구 사항"]을(를) 충족하는 환경에서 설치 명령을 실행합니다.

NetApp Console은 AI Data Engine을 위한 인프라를 프로비저닝하지 않습니다. 단일 노드 배포의 경우 Linux VM을 준비하면 설치 프로그램이 나머지 설정을 수행합니다. 다중 노드 배포의 경우 Kubernetes 클러스터를 준비합니다. 두 경우 모두 인프라가 요구 사항을 충족해야 합니다. 그런 다음 NetApp Console에서 미리 생성된 설치 명령을 복사하여 대상 호스트에서 실행합니다. 이 명령은 런타임을 부트스트랩하고 AI Data Engine 스택을 자동으로 배포합니다.

단일 노드 배포는 일반적으로 45분 이내에 완료됩니다. 다중 노드 배포는 일반적으로 30분 이내에 완료됩니다. 설치 프로그램에는 구성 요소 시작 중 발생하는 일시적인 문제를 처리하기 위한 시간 초과 및 재시도 기능이 내장되어 있습니다.

자세한 절차는 link:deploy-aide-single-node.html["AI Data Engine을 단일 노드 배포로 배포하십시오."] 및 link:deploy-aide-multi-node.html["AI Data Engine을 멀티 노드 배포 방식으로 배포하십시오."]를 참조하십시오.



[[deployment-with-a-proxy]]
== 프록시를 사용한 배포

호스트 또는 클러스터가 아웃바운드 프록시를 통해서만 인터넷에 연결되는 경우, 프록시와 함께 AI Data Engine을 배포하십시오. 프록시 단계는 배포 유형마다 다르므로, 각 유형에는 표준 배포 항목을 대체하는 자체 전체 항목이 있습니다.

전체 단계는 지원되는 프록시 유형에 대한 link:configure-proxy.html["AI Data Engine용 프록시에 대해 알아보기"] 및 프록시에서 허용할 엔드포인트에 대한 link:aide-requirements.html#outbound-internet-access["아웃바운드 인터넷 액세스"]을(를) 참조하십시오.
