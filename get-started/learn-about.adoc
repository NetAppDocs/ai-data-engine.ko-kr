= AI Data Engine에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine은 스토리지 시스템에 저장된 정형 및 비정형 데이터에 대한 가시성을 제공하는 메타데이터 인텔리전스 서비스입니다. AI Data Engine은 스토리지 시스템을 스캔하고 파일 시스템 메타데이터를 카탈로그화하여 스토리지 최적화 기회를 파악하고, 데이터를 조사하고, 데이터를 이동하거나 복사하지 않고 메타데이터를 분석하여 거버넌스 정책을 시행할 수 있도록 지원합니다.



[[what-ai-data-engine-does]]
== AI Data Engine 의 기능

AI Data Engine은 연결된 스토리지 시스템을 스캔하여 파일 시스템 메타데이터를 추출하고 각 스캔 주기 후에 업데이트되는 카탈로그를 구축합니다. 이 카탈로그에서 다음 작업을 수행할 수 있습니다.

* 대시보드에서 스토리지 최적화 인사이트를 확인할 수 있으며, 여기에는 조직의 콜드 및 오래된 임계값을 충족하는 파일, 중복 파일 등 잠재적으로 회수 가능한 스토리지를 보유한 데이터 소유자가 포함됩니다.
* 유연한 메타데이터 필터를 사용하여 데이터를 조사하고 타겟 데이터 그룹을 구축하십시오.
* 조사 기준을 재사용 가능한 규칙으로 저장하는 정책을 생성합니다.
* 데이터에 대한 조치 수행: 정책 기준에 부합하는 파일에 태그 지정, 보관, 복사 또는 삭제




[[storage-optimization-and-data-governance]]
== 스토리지 최적화 및 데이터 거버넌스

AI Data Engine은 스토리지 시스템에 저장된 정형 및 비정형 데이터에 대한 스토리지 최적화 및 데이터 라이프사이클 관리에 중점을 둡니다.



[[who-uses-ai-data-engine]]
== AI Data Engine을 사용하는 사람

AI Data Engine은 다음과 같은 사용자를 위해 설계되었습니다.

* *스토리지 관리자*는 조직의 콜드 및 오래된 임계값에 맞는 파일을 보유한 데이터 소유자를 식별 및 모니터링하고, 중복 파일을 식별하고, 스토리지 최적화 기회를 평가해야 합니다.
* 스토리지 환경 전반에 걸쳐 어떤 정형 및 비정형 데이터가 존재하는지에 대한 중앙 집중식 보기가 필요한 *IT 운영 팀*.




[[where-ai-data-engine-lives]]
== AI Data Engine 있는 곳

AI Data Engine은 NetApp Console의 *AI 데이터 허브 > AI Data Engine*에서 액세스할 수 있습니다. AI Data Engine은 현재 비공개 미리 보기로 제공되고 있습니다. 액세스 권한을 요청하려면 NetApp 담당자에게 문의하십시오. AI Data Engine은 AIDE Lite(단일 VM 설치)로 배포할 수 있으며, 클라우드 계정의 가상 머신 또는 온프레미스 환경의 머신과 같이 사용자가 관리하는 Linux 인프라에 설치할 수 있습니다. 대규모 환경에서 Kubernetes 기반의 고가용성이 필요한 경우 AIDE Enterprise를 대신 배포할 수 있습니다.

AI Data Engine은 NetApp ONTAP 및 StorageGRID 시스템뿐만 아니라 NFS, SMB/CIFS 또는 S3 프로토콜을 지원하는 NetApp 이외의 시스템에서도 데이터를 스캔합니다.
