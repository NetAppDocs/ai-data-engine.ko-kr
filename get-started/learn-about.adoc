= AI Data Engine에 대해 알아보십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine(AIDE)은 스토리지 시스템에 저장된 정형 및 비정형 데이터에 대한 가시성을 제공하는 메타데이터 인텔리전스 서비스입니다. AI Data Engine은 스토리지 시스템을 스캔하고 파일 시스템 메타데이터를 카탈로그화하여 스토리지 최적화 기회를 파악하고, 데이터를 조사하며, 거버넌스 정책을 시행할 수 있도록 합니다.



[[what-ai-data-engine-does]]
== AI Data Engine 의 기능

AI Data Engine은 연결된 데이터 소스를 스캔하여 각 스캔 주기마다 갱신되는 검색 가능한 메타데이터 카탈로그를 구축합니다. 카탈로그에서 다음 작업을 수행할 수 있습니다.

* *스토리지를 파악하십시오.* 데이터 용량, 소유자, 저장 위치를 확인하십시오.
* *용량 확보.* 사용되지 않거나, 오래되었거나, 중복된 데이터를 찾고, 어떤 데이터 소유자가 가장 많은 데이터를 보유하고 있는지 확인하여 데이터 정리를 위해 누구에게 연락해야 할지 파악하십시오.
* *접근 위험 요소를 파악하십시오.* 권한이 열려 있는 디렉터리를 식별하여 검토 우선순위를 정하십시오.
* *조사하고 정리하세요.* 메타데이터 필터를 사용하여 관심 있는 데이터를 찾고, 태그를 지정하고, 기준을 정책으로 저장하여 시간이 지남에 따라 모니터링할 수 있습니다.
* *데이터에 대해 조치를 취하십시오.* 검토한 파일에 태그를 지정하거나 보관, 복사 또는 삭제하십시오.
* *AI를 위한 데이터 준비.* 승인된 AI 클라이언트가 메타데이터를 검색하고 데이터에 대한 작업을 수행할 수 있도록 하십시오.




[[storage-optimization-and-data-lifecycle-management]]
== 스토리지 최적화 및 데이터 라이프사이클 관리

메타데이터를 사용하여 조직의 콜드 및 비활성 임계값을 충족하는 파일 및 중복 파일 등 검토가 필요한 데이터를 식별하십시오. 데이터를 유지, 태그 지정, 아카이브, 복사 또는 삭제할지 결정하기 전에 결과를 조사하십시오.

스토리지 최적화 관련 인사이트는 활용 가능한 기회를 보여줍니다. 확보할 수 있는 용량은 취하는 조치에 따라 달라집니다.



[[governed-ai-access]]
== AI 접근 제어

관리형 AI 액세스를 통해 AI 클라이언트는 사용자가 설정한 범위 내에서 Model Context Protocol(MCP)을 통해 메타데이터를 검색할 수 있습니다. 컬렉션을 생성하여 사용할 수 있는 데이터를 선택합니다. 컬렉션은 AI 클라이언트에서 사용할 수 있도록 제공하는 스캔된 데이터 집합입니다. Microsoft Entra ID 범위를 정의하여 사용자가 검색할 수 있는 컬렉션을 제어합니다.

AI 클라이언트는 메타데이터만 처리합니다. 파일 내용을 가져올 수 없습니다.

link:../mcp/learn-about-mcp.html["통제된 AI 액세스에 대해 자세히 알아보십시오"].



[[who-uses-ai-data-engine]]
== AI Data Engine을 사용하는 사람

다음 예시는 다양한 사람들이 AI Data Engine을 어떻게 사용할 수 있는지 보여줍니다:

* 조직의 콜드 및 비활성 임계값에 부합하는 파일을 검토하고, 중복 파일을 식별하며, 스토리지 최적화 기회를 평가해야 하는 *스토리지 관리자*.
* 스토리지 환경 전반에 걸쳐 어떤 정형 및 비정형 데이터가 존재하는지에 대한 중앙 집중식 보기가 필요한 *IT 운영 팀*.
* 승인된 컬렉션의 메타데이터를 검색하고 작업할 데이터에 태그를 지정하기 위해 AI 클라이언트를 사용하는 *데이터 또는 AI 팀 구성원*.
* AI 툴을 도입 중이며 AI 클라이언트가 어떤 컬렉션을 검색할 수 있고 누가 이를 사용할 수 있는지 선택해야 하는 *IT 책임자*.




[[where-ai-data-engine-runs]]
== AI Data Engine이 실행되는 위치

NetApp Console의 *AI data hub > AI Data Engine*에서 AI Data Engine에 액세스합니다. 스캔 및 카탈로그 서비스는 클라우드 계정 또는 온프레미스 환경 등 사용자가 제공하는 인프라에서 실행됩니다. 대규모 환경에서 고가용성이 필요한 경우 Linux VM의 AIDE 단일 노드 배포 또는 Kubernetes 클러스터의 AIDE 다중 노드 배포를 선택하십시오.

link:../deploy/deployment-overview.html["배포 옵션에 대해 자세히 알아보십시오."].

AI Data Engine은 연결한 지원되는 데이터 소스를 스캔합니다. 자세한 내용은 link:../data-sources/connect-data-source.html["데이터 소스 연결"]을(를) 참조하십시오.
