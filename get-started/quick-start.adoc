= AI Data Engine 빠른 시작
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine을 시작하려면 서비스를 배포하고 스토리지 시스템을 연결한 다음 첫 번째 조사를 시작하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] 검토 요구사항
[role="quick-margin-para"]
link:../deploy/aide-requirements.html["AIDE 요구 사항"] 및 link:../deploy/deployment-overview.html["배포 모드에 대해 알아보기"]를 검토하여 AIDE Lite 또는 AIDE Enterprise를 설치할지 여부를 결정하십시오. AI Data Engine은 NetApp Console에서 비공개 미리 보기로 제공됩니다. AI Data Engine을 배포할 수 있도록 액세스를 요청하려면 NetApp 담당자에게 문의하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] AI Data Engine 배포
[role="quick-margin-para"]
NetApp Console에서 link:../deploy/deploy-aide-lite.html["AIDE Lite"] 또는 link:../deploy/deploy-enterprise.html["AIDE Enterprise"]를 배포합니다. 설정 페이지에서 설치 위치 및 구성 크기를 선택하고 설치 명령을 실행하는 과정을 안내합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3"] 데이터 소스 연결
[role="quick-margin-para"]
link:../data-sources/connect-data-source.html["데이터 소스 연결"] 스캔을 시작합니다. AI Data Engine은 지정한 스토리지 시스템의 파일 시스템 메타데이터를 카탈로그화합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"] 데이터 탐색
[role="quick-margin-para"]
link:../investigate/understand-dashboard.html["대시보드"]를 열어 스토리지 최적화 관련 정보를 확인하거나, link:../investigate/investigate-data.html["조사"]로 이동하여 메타데이터를 직접 검색하고 필터링하세요.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["다섯"] 정책 생성
[role="quick-margin-para"]
link:../policies/create-policy.html["조사 필터를 정책으로 저장"] 동일한 기준에 부합하는 파일을 시간에 따라 모니터링할 수 있습니다. 알림을 보내거나, 일치하는 파일을 영구적으로 삭제하거나, 결과를 추적하도록 정책을 구성할 수 있습니다.
