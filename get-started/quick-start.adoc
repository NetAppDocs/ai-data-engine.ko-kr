= AI Data Engine 빠른 시작
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
서비스를 배포하고 데이터 소스를 연결한 다음 첫 번째 조사를 시작하여 AI Data Engine(AIDE)을 가동 및 실행하십시오. 또한 관리되는 AI 액세스를 통해 AI 클라이언트가 메타데이터를 검색할 수 있도록 허용할 수도 있습니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] link:../deploy/aide-requirements.html["요구사항을 검토하고 배포 유형을 선택하십시오"]
[role="quick-margin-para"]
요구 사항 및 link:../deploy/deployment-overview.html["배포 유형에 대해 알아보세요"]을(를) 검토하여 AIDE 단일 노드 또는 다중 노드 배포를 설치할지 결정하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] link:../deploy/deployment-overview.html["AI Data Engine 배포"]
[role="quick-margin-para"]
NetApp Console에서 link:../deploy/deploy-aide-single-node.html["AIDE 단일 노드 배포"] 또는 link:../deploy/deploy-aide-multi-node.html["AIDE 다중 노드 배포"]를 배포하십시오. 설정 페이지에서 설치 위치와 구성 크기를 선택하고 설치 명령을 실행하는 과정을 안내합니다. 호스트 또는 클러스터가 프록시를 통해서만 인터넷에 연결되는 경우 대신 link:../deploy/configure-proxy.html["프록시를 사용하여 배포"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3"] link:../data-sources/connect-data-source.html["데이터 소스 연결"]
[role="quick-margin-para"]
데이터 소스를 연결하여 스캔을 시작하십시오. AI Data Engine은 연결한 데이터 소스의 메타데이터를 카탈로그화합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["네"] link:../investigate/understand-dashboard.html["데이터 탐색"]
[role="quick-margin-para"]
대시보드를 열어 스토리지 최적화 인사이트를 확인하거나, link:../investigate/investigate-data.html["조사"](으)로 이동하여 메타데이터를 직접 검색하고 필터링하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["다섯"] link:../policies/create-policy.html["정책 만들기"]
[role="quick-margin-para"]
조사 필터를 정책으로 저장하여 동일한 기준과 일치하는 파일을 지속적으로 모니터링할 수 있습니다. 정책을 구성하여 알림을 보내거나, 일치하는 파일을 영구적으로 삭제하거나, 결과를 추적할 수 있습니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["6"] link:../mcp/quick-start-mcp.html["선택 사항: AI 접근 권한 관리 설정"]
[role="quick-margin-para"]
AI 클라이언트가 사용자가 선택한 컬렉션의 메타데이터를 검색할 수 있도록 합니다. 고급 사용자는 메타데이터를 검색하고 데이터에 대한 작업을 수행할 수 있습니다.
