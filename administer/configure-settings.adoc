= AI Data Engine에서 데이터 분류 임계값 및 액세스 스캔 구성
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
콜드 및 오래된 데이터 임계값을 활용하여 AI Data Engine(AIDE)을 사용해 최적화할 수 있는 스토리지를 찾을 수 있습니다. 권한 스캔 및 Active Directory 통합을 통해 액세스 위험을 파악하고 이해할 수 있습니다. 조직의 데이터 분류, 보존 및 액세스 정책에 맞게 설정하십시오.



[[before-you-begin]]
== 시작하기 전에

_AI Data Engine 관리자_ 역할이 있어야 합니다.



[[what-is-cold-and-stale-data]]
== 콜드 데이터 및 스테일 데이터란 무엇입니까?

콜드 데이터:: 콜드 데이터 임계값 내에 액세스되지 않은 파일입니다. 콜드 데이터는 조직에서 보존 및 비즈니스 정책에 따라 최적화할 수 있는 스토리지를 식별하는 데 사용할 수 있는 핵심 지표입니다.
오래된 데이터:: 오래된 데이터 임계값 내에 수정되지 않은 파일입니다. 오래된 데이터는 조직에서 최근에 변경되지 않은 파일을 식별하는 데 도움이 되며, 정책에 따라 해당 파일을 모니터링하거나 관리할 수 있습니다.


이러한 임계값은 대시보드 요약, 조사에서 비활성 또는 오래된 데이터 필터를 적용할 때 표시되는 파일, 그리고 정책 대상 파일에 영향을 미칩니다. 조직에서 데이터를 평가하기 전에 데이터가 사용되지 않거나 변경되지 않은 상태로 얼마나 오래 유지될 수 있는지를 반영하는 임계값을 선택하십시오. 임계값이 짧을수록 더 많은 데이터가 비활성 또는 오래된 데이터로 분류되고, 임계값이 길수록 가장 오랫동안 비활성 상태였던 데이터로 결과가 좁혀집니다.


NOTE: 기본 임계값은 시작점으로 제공되는 제품 기본값입니다. 법률, 규정 준수 또는 업계 표준 보존 기간을 나타내는 것은 아닙니다. 조직의 특정 정책 및 요구 사항을 반영하여 임계값을 설정하십시오.

콜드 및 스테일 임계값 변경 사항은 다음 스캔 주기가 완료된 후에 적용됩니다.



[[set-the-cold-data-threshold]]
== 콜드 데이터 임계값을 설정하세요

조직에서 파일을 보관, 삭제 또는 모니터링 대상으로 평가하기 전에 파일에 액세스하지 않고 보관할 수 있는 기간을 결정하십시오. 파일 크기에 따라 분류를 제한하거나 특정 파일 형식 또는 경로를 제외할 수도 있습니다.

.단계
. AI Data Engine UI에서 *구성* > *일반 설정*을 선택합니다.
. *콜드 데이터 정의*를 확장하고, 콜드 데이터 분류가 비활성화된 경우 활성화하십시오.
. *경과 시간 기준*에서 경과 시간을 결정하는 타임스탬프를 선택합니다. 최근에 사용되지 않은 파일을 식별하려면 *마지막 액세스*를 선택하고, 최근에 변경되지 않은 파일을 식별하려면 *마지막 수정*을 선택합니다.
. *콜드 기간 임계값*을 설정합니다. 기본값은 1년입니다.
. 중요한 파일에 집중하려면 *최소 파일 크기(MiB)*와 *최대 파일 크기 제한(MiB)*을 설정하세요.
. 선택 사항: 특정 파일을 이 분류에서 제외하려면 *제외할 파일 형식* 및 *제외할 경로*를 입력하십시오. 파일과 전체 경로를 입력하고, 여러 항목은 쉼표로 구분하십시오.
. *저장*을 선택합니다.




[[set-the-stale-data-threshold]]
== 오래된 데이터 임계값을 설정합니다

조직의 데이터 라이프사이클 정책에 따라 파일을 검토하기 전에 변경 없이 보관할 수 있는 기간을 결정하십시오. 파일 크기에 따라 분류를 제한하거나 특정 파일 형식 또는 경로를 제외할 수도 있습니다.

.단계
. AI Data Engine UI에서 *구성* > *일반 설정*을 선택합니다.
. *오래된 데이터 정의*를 확장하고, 오래된 데이터 분류가 비활성화된 경우 활성화하십시오.
. *경과 시간 기준*에서 경과 시간을 결정하는 타임스탬프를 *최종 수정일* 또는 *최종 액세스일* 중에서 선택합니다.
. *오래된 데이터의 유효기간*을 설정합니다. 기본값은 3년입니다.
. 중요한 파일에 집중하려면 *최소 파일 크기(MiB)*와 *최대 파일 크기 제한(MiB)*을 설정하세요.
. 선택 사항: 특정 파일을 이 분류에서 제외하려면 *제외할 파일 형식* 및 *제외할 경로*를 입력하십시오. 파일과 전체 경로를 입력하고, 여러 항목은 쉼표로 구분하십시오.
. *저장*을 선택합니다.




[[find-access-risks-with-permission-scanning]]
== 권한 스캔을 통해 액세스 위험을 찾아냅니다.

정책에서 허용한 인원보다 더 많은 사람이 접근할 수 있는 파일과 폴더를 찾으려면 권한 검사를 활성화하십시오. 결과를 검토하려면 link:../investigate/investigate-directories.html["디렉토리 조사"]을(를) 참조하십시오.

.단계
. AI Data Engine UI에서 *구성* > *일반 설정*을 선택합니다.
. *권한 검사*를 확장하고 토글을 켜십시오.
+
권한 스캔을 중지하려면 토글을 끄십시오.





[[show-user-and-group-names-with-active-directory]]
== Active Directory에서 사용자 및 그룹 이름을 표시합니다

데이터를 검토할 때 숫자 ID 대신 사용자 이름과 권한을 확인해야 하는 경우 AI Data Engine을 Active Directory에 연결하십시오. 환경에서 NFS를 사용하는 경우 숫자 사용자 ID(UID)와 그룹 ID(GID)를 디렉터리 사용자 및 그룹에 매핑할 수도 있습니다.

필수 조건 및 절차는 link:configure-ad-nfs.html["NFS에 대한 Active Directory ID 매핑 구성"]을(를) 참조하십시오.
