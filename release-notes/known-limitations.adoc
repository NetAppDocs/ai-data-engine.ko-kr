= AI Data Engine의 알려진 제한 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알려진 제한 사항은 이번 AI Data Engine 릴리스에서 지원되지 않는 기능 또는 올바르게 상호 운용되지 않는 기능을 나타냅니다. 제품을 배포하거나 사용하기 전에 이러한 제한 사항을 검토하십시오.



[[deployment]]
== 구축

Lite 버전과 Enterprise 버전은 서로 독립적입니다.:: AIDE Lite와 AIDE Enterprise는 서로 다른 배포 모드입니다. 기존 배포 환경을 한 모드에서 다른 모드로 마이그레이션하는 데 지원되는 경로는 없습니다.




[[policies-and-actions]]
== 정책 및 조치

정책에 따라 실행되는 조치는 제한적입니다.:: 정책을 생성할 때 사용 가능한 자동화된 작업은 영구 삭제 및 이메일 알림으로 제한됩니다. 이번 릴리스에서는 정책을 통한 자동화된 보관 및 태그 지정 작업은 사용할 수 없습니다. 데이터 상태를 시간 경과에 따라 모니터링하기 위해 작업이 없는 정책을 생성할 수 있습니다.




[[tags]]
== 태그

태그는 삭제하거나 이름을 변경할 수 없습니다.:: 이번 릴리스에서는 태그 관리 기능이 제공되지 않습니다. 태그를 생성하면 시스템에 계속 저장됩니다. 항목에 태그를 적용하거나 제거할 수는 있지만, 태그 정의 자체를 삭제하거나 오타가 포함된 태그 이름을 수정할 수는 없습니다.
