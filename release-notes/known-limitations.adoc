= AI Data Engine의 알려진 제한 사항
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
알려진 제한 사항은 AI Data Engine(AIDE)에서 지원되지 않는 기능 또는 올바르게 상호 운용되지 않는 기능을 나타냅니다. 제품을 배포하거나 사용하기 전에 이러한 제한 사항을 검토하십시오.



[[deployment]]
== 구축

단일 노드 배포와 다중 노드 배포는 서로 독립적입니다.:: AIDE 단일 노드 배포와 AIDE 다중 노드 배포는 서로 다른 배포 유형입니다. 기존 배포를 한 유형에서 다른 유형으로 마이그레이션하는 데 지원되는 경로는 없습니다.
프록시 지원은 제한적입니다:: 포워드 프록시를 사용하여 AI Data Engine을 배포할 수 있지만, 다음 프록시 기능은 지원되지 않습니다:
+
--
* 사용자 지정 인증 기관을 사용하여 HTTPS 트래픽을 복호화하고 다시 서명하는 TLS 검사 프록시.
* 프록시에 대한 NTLM, Kerberos 또는 클라이언트 인증서 인증. 인증을 사용하지 않거나 기본 인증을 사용하십시오.
* SOCKS 프록시.
* 프록시 자동 구성(PAC 파일 또는 WPAD). 설치 프로그램에 프록시 호스트와 포트를 직접 제공하십시오.
* 목적지마다 다른 프록시를 사용합니다. 하나의 프록시가 모든 AI Data Engine 인터넷 트래픽을 처리합니다.
* 프록시 주소로 IPv6 주소. 대신 호스트 이름을 사용하십시오. 호스트 이름은 IPv6로 확인될 수 있습니다.
* 망 분리 설치 환경의 프록시. 설치 프로그램은 망 분리 설치에서 프록시 옵션을 거부합니다.
+
지원되는 프록시 구성에 대해서는 link:../deploy/configure-proxy.html["AI Data Engine용 프록시에 대해 알아보기"]을(를) 참조하십시오.



--




[[policies-and-actions]]
== 정책 및 조치

정책에 따라 실행되는 조치는 제한적입니다.:: 정책을 생성할 때 사용 가능한 자동화된 작업은 영구 삭제 및 이메일 알림으로 제한됩니다. 정책에서 자동화된 보관 및 태그 지정 작업은 사용할 수 없습니다. 시간 경과에 따른 데이터 상태를 모니터링하기 위해 작업이 없는 정책을 생성할 수 있습니다.




[[tags]]
== 태그

태그는 삭제하거나 이름을 변경할 수 없습니다.:: 태그를 생성하면 시스템에서 계속 사용할 수 있습니다. 아이템에 태그를 적용하거나 제거할 수는 있지만, 태그 정의 자체를 삭제하거나 이름을 변경하거나 오타가 있는 태그 이름을 수정할 수는 없습니다. 태그 이름은 대소문자를 구분하므로  `Finance`와  `finance`는 서로 다른 태그입니다.




[[governed-ai-access-mcp]]
== 관리형 AI 액세스(MCP)

MCP 검색 필터는 제한적입니다:: AI 클라이언트는 파일 이름 접두사, 파일 형식 및 소유자로만 파일을 검색할 수 있습니다. 크기, 날짜 또는 폴더로 파일을 요청하면 AI 클라이언트는 결과를 페이지별로 살펴봐야 하며 답변이 불완전할 수 있습니다.
MCP 태그 작업에는 제한이 있습니다:: AI 클라이언트는 태그가 지정된 파일 목록을 표시할 수 없으며, 한 번에 하나의 파일에만 태그를 추가하거나 제거할 수 있습니다.
