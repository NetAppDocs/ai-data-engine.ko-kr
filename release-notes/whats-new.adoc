[[ai-data-engine-1-1-0]]
== AI Data Engine 1.1.0

AI Data Engine은 NetApp Console을 통해 관리되는 메타데이터 인텔리전스 서비스로, 연결된 시스템을 스캔하고 메타데이터 카탈로그를 구축하며 스토리지 최적화 및 대규모 데이터 관리를 위한 가시성과 툴을 제공합니다. AI Data Engine은 link:../deploy/deployment-overview.html["AIDE Lite"]으로 배포하거나, 대규모 환경에서 Kubernetes 기반 고가용성이 필요한 경우 AIDE Enterprise로 배포할 수 있습니다.

새로운 기능:

link:../investigate/understand-dashboard.html["스토리지 용량 복구"]:: 설정된 임계값을 기준으로 연결된 시스템 전체에서 콜드, 오래된, 중복 데이터를 식별하고, 어떤 시스템과 데이터 소유자가 이러한 데이터를 가장 많이 보유하고 있는지 확인하십시오.
link:../investigate/investigate-data.html["비용 및 위험 감소"]:: 연결된 모든 시스템에서 액세스 시간, 수정 날짜, 생성 날짜, 파일 크기, 중복 여부 및 기타 기준에 따라 필터링하여 조직의 데이터 관리 목표에 부합하는 파일을 찾으십시오. 검색 결과를 바로 활용하거나 기준을 정책으로 저장할 수 있습니다.
link:../policies/create-policy.html["데이터를 지속적으로 관리합니다"]:: 콜드 파일 또는 크기가 큰 파일 등 반복되는 데이터 조건을 시간이 지남에 따라 추적하기 위해 필터 기준을 명명된 정책으로 저장하고, 영향을 받는 파일 수가 변경될 때 알림을 받으십시오.
link:../investigate/take-actions.html["스토리지 비용 절감"]:: NFS 또는 SMB/CIFS 대상으로 파일을 복사 및 보관하거나, 추적을 위해 항목에 태그를 지정하거나, 보존 요구 사항에 따라 파일을 영구적으로 삭제하여 조직의 데이터 라이프사이클 정책을 시행하십시오.
link:../administer/manage-users-roles.html["관리자 및 뷰어 역할 할당"]:: 조직 내 사용자에게 AI Data Engine 관리자 또는 뷰어 역할을 할당하여 데이터를 조사하고 조치를 취할 수 있는 사용자를 제어할 수 있습니다.
link:../investigate/use-filters.html["중복 데이터 제거"]:: 연결된 시스템 전체에서 중복된 파일을 찾습니다. 중복 속성 또는 파일 해시를 기준으로 필터링하여 중복 그룹을 직접 검토하고 조치할 수 있습니다.
link:../investigate/understand-dashboard.html["데이터 소유자에게 책임을 부여하십시오"]:: 대시보드에서 콜드, 오래된 데이터 또는 중복 데이터의 비율이 가장 높은 데이터 소유자를 파악한 다음, 조사 보기에서 소유자 또는 그룹별로 필터링하여 정책에 따라 결과를 검토하고 관리하십시오.
