= AI Data Engine에서 스캔 상태 모니터링
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
대시보드 또는 조사 결과에 따라 조치를 취하기 전에 기본 데이터가 최신 상태인지 확인하십시오. 스캔이 제대로 작동하고 결과가 최신 데이터를 반영하는지 확인하십시오.



[[verify-scan-status-and-coverage]]
== 스캔 상태 및 범위 확인

모든 스토리지 시스템이 연결되어 있고 스캔 중인지 확인하십시오.

.단계
. AI Data Engine UI에서 *구성*을 선택합니다.
. *스캔된 시스템* 탭에서 예상되는 모든 스토리지 시스템이 목록에 표시되고 스캔이 활성화되어 있는지 확인하십시오.
. 시스템 행에서 *세부 정보 보기*를 선택하여 스캔 진행 상황 및 오류를 확인하십시오. 자세한 내용은 link:../data-sources/manage-data-sources.html["데이터 소스 관리"]을 참조하십시오.




[[validate-that-investigation-findings-reflect-current-data]]
== 조사 결과가 최신 데이터를 반영하는지 검증합니다.

대시보드에 콜드 데이터나 오래된 데이터가 많이 표시되는 경우, 해당 데이터를 기반으로 의사 결정을 내리기 전에 수치가 최신 정보인지 확인하십시오.

* 해당 문제와 관련된 각 스토리지 시스템의 마지막 스캔 시간을 확인하십시오. 최근에 스캔하지 않은 시스템은 콜드 데이터 및 오래된 데이터를 과소 또는 과다 보고할 수 있습니다.
* 해당 시스템에 대한 검사 범위가 완료되었는지 확인하십시오. 부분 검사(일시 중지, 진행 중 또는 오류 발생)는 일부 데이터가 아직 평가되지 않았음을 의미합니다.
* 검사 범위가 불완전해 보이면 다음 검사 주기까지 기다리거나 기본 오류를 해결하십시오.
