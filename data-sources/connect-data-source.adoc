= 데이터 소스를 AI Data Engine에 연결합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine은 스토리지 시스템을 스캔하여 메타데이터를 수집하고 분석합니다. 데이터 소스를 추가하려면 온보딩 마법사를 완료하십시오. 마법사는 연결 정보, 스캔 범위 및 소스 유형 설정을 수집합니다. 시스템을 추가한 후 스캔을 활성화하여 메타데이터 수집을 시작하십시오.

.시작하기 전에
* AI Data Engine에서 데이터 소스를 연결하고 구성하려면 _AI Data Engine 관리자_ 권한이 있어야 합니다.
* AI Data Engine에 추가하기 전에 Console Agent를 사용하여 NetApp Console에서 스토리지 시스템을 검색하십시오. 이는 온프레미스 ONTAP 클러스터, Cloud Volumes ONTAP, Amazon FSx for NetApp ONTAP, Google Cloud NetApp Volumes 및 Azure NetApp Files를 포함한 모든 지원되는 스토리지 유형에 적용됩니다. 온프레미스 ONTAP 클러스터에 대해서는 NetApp Console 설명서의 link:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html["온프레미스 ONTAP 클러스터 검색"]를 참조하십시오. 직접 검색으로는 AI Data Engine 등의 데이터 서비스를 사용할 수 없습니다.
* AI Data Engine이 데이터 소스에 연결하는 데 필요한 네트워크 연결이 열려 있는지 확인하십시오. link:../deploy/aide-requirements.html["AI Data Engine 요구 사항"]을 참조하십시오.




[[add-a-data-source]]
== 데이터 소스 추가

.단계
. AI Data Engine UI에서 *구성*을 선택합니다.
. *스캔된 시스템* 탭에서 *시스템 추가*를 선택합니다.
. 소스 유형을 선택하십시오:
+
[cols="1,2"]
|===
| 소스 유형 | 설명 


| *파일 공유 그룹* | 클라우드 또는 온프레미스의 NFS 또는 SMB/CIFS 파일 공유를 명명된 그룹으로 추가합니다. 


| *데이터베이스* | 선택한 스키마를 스캔할 데이터베이스 서버를 추가합니다. 


| *StorageGRID* | NetApp StorageGRID에서 S3 프로토콜을 사용하여 데이터를 스캔합니다. 
|===
. 사용하려는 소스 유형에 대한 연결 정보를 입력하십시오.
+
[cols="1,3"]
|===
| 소스 유형 | 필수 정보 


| *파일 공유 그룹* | 공유 그룹의 이름, 공유 호스트 및 경로 세부 정보. 


| *데이터베이스* | 데이터베이스 유형, 호스트, 포트 및 인증 자격 증명. 


| *StorageGRID* | 시스템 이름, S3 엔드포인트 URL, S3 액세스 키 및 비밀 키. 
|===
. 선택 사항을 검토하고 *확인*을 선택하여 데이터 소스를 추가합니다.




[[activate-scanning]]
== 스캔 활성화

데이터 소스를 구성한 후에도 스캔이 자동으로 시작되지는 않습니다. 각 시스템에 대해 스캔 기능을 활성화해야 합니다.

.단계
. AI Data Engine UI에서 *구성*을 선택합니다.
. *스캔된 시스템* 탭에서 스캔할 시스템을 찾으십시오.
. *스캔 활성화*를 선택합니다.


.결과
스캔된 시스템 탭에서 시스템 상태가 업데이트되어 스캔이 실행 중임을 보여줍니다. 스캔 진행 상황을 모니터링하고 AI Data Engine이 데이터 리소스를 색인화하는지 확인하려면 link:manage-data-sources.html["데이터 소스 관리"] 및 link:monitor-scanning-health.html["스캔 상태 모니터링"]을 참조하십시오.
