= AI Data Engine의 메타데이터 필터
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine 조사 보기에서는 메타데이터 필터를 사용하여 특정 데이터 그룹으로 결과를 좁힐 수 있습니다. 하나 이상의 필터를 동시에 적용하여 검사하거나 조치를 취할 파일을 정의할 수 있습니다.



[[time-filters]]
== 시간 필터

[cols="1,2"]
|===
| 필터 | 설명 


| 최근 생성됨 | 파일 생성 날짜를 기준으로 파일을 필터링합니다. 


| 최종 수정일 | 최종 수정일을 기준으로 파일을 필터링합니다. 


| 마지막 접속일 | 파일을 마지막 액세스 날짜별로 필터링합니다. 이 필터를 사용하여 사용 빈도가 낮은 오래된 데이터를 식별할 수 있습니다. 


| 검색된 시간 | AI Data Engine이 스캔 중에 파일을 처음 감지한 시점을 기준으로 파일을 필터링합니다. 
|===


[[file-attribute-filters]]
== 파일 속성 필터

[cols="1,2"]
|===
| 필터 | 설명 


| 파일 형식 | 파일 확장자 또는 유형 분류별로 필터링합니다. 목록에서 하나 이상의 파일 유형을 선택합니다. 


| 파일 크기 | 파일 크기로 필터링합니다. 최소값, 최대값 또는 범위를 입력합니다. 


| 파일/디렉토리 경로 | 파일 또는 해당 파일이 포함된 디렉터리의 전체 경로 또는 부분 경로로 필터링합니다. 


| 파일/디렉토리 소유자 | 파일 또는 디렉터리의 소유자인 사용자 또는 그룹으로 필터링합니다. 


| 파일 해시 | 파일의 해시 값으로 필터링하여 특정 파일을 찾거나 중복 콘텐츠를 확인할 수 있습니다. 


| 중복 | 카탈로그에서 중복 복사본이 감지된 파일만 표시하도록 필터링합니다. 


| 디렉터리 유형 | 디렉터리 유형별로 필터링합니다. 디렉터리 탭에 적용됩니다. 
|===


[[source-filters]]
== 소스 필터

[cols="1,2"]
|===
| 필터 | 설명 


| 데이터 컨테이너 | 특정 볼륨 또는 공유로 필터링합니다. 


| 시스템 | 특정 클러스터로 필터링합니다. 


| 시스템 유형 | 스토리지 시스템 유형별로 필터링합니다. 
|===


[[governance-filters]]
== 거버넌스 필터

[cols="1,2"]
|===
| 필터 | 설명 


| 태그 | 특정 비즈니스 태그가 적용된 파일을 필터링합니다. 


| 정책 | 저장된 특정 정책과 일치하는 파일만 필터링합니다. 필터 목록에 정책 이름이 표시됩니다. 
|===


[[access-filters]]
== 액세스 필터

[cols="1,2"]
|===
| 필터 | 설명 


| 접근 권한이 있는 사용자 수 | 접근 권한이 있는 사용자 또는 그룹 수를 기준으로 파일을 필터링합니다. 이를 통해 접근 권한이 광범위한 데이터를 식별할 수 있습니다. 


| 사용자/그룹 권한 | 접근 권한이 있는 특정 사용자 또는 그룹으로 파일을 필터링합니다. 
|===


[[combining-filters]]
== 필터 조합

필터는 AND 논리로 결합되므로 결과는 적용된 모든 필터와 동시에 일치해야 합니다.
