= AI Data Engine 대시보드로 스토리지 상태 평가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
조사 대상을 결정하기 전에 스토리지 상태를 파악해야 합니다. 조직의 콜드 데이터 및 오래된 데이터 분류 기준에 부합하는 스토리지 용량이 얼마나 되는지, 그리고 이러한 범주에 속하는 데이터를 가장 많이 보유하고 있는 시스템이나 담당자는 누구인지 알아야 합니다. 예를 들어, 용량 부족 경고에 대응하는 스토리지 관리자는 스캔한 스토리지의 상당 부분이 콜드 데이터임을 확인한 후 가장 큰 영향을 미치는 시스템으로 이동하여 즉시 조사를 시작할 수 있습니다.

NetApp Console에서 *AI 데이터 허브* > *AI Data Engine*을 선택합니다. 대시보드가 기본적으로 열립니다. 대시보드는 인사이트를 *스토리지 최적화*, *액세스 노출*, *정형 데이터*의 세 가지 탭으로 구성합니다.



[[understand-how-much-storage-is-affected]]
== 영향을 받는 스토리지 용량 파악

스캔한 스토리지 중 얼마나 많은 부분이 사용되지 않거나, 오래되었거나, 노출되었는지 파악하십시오. 요약 패널은 스캔한 환경 전체에서 문제의 규모를 보여줍니다:

* *데이터 리소스*: 현재 스캔 중인 볼륨, 공유 및 버킷의 개수입니다.
* *스캔된 항목 수*: 스캔된 모든 데이터 리소스에서 색인화된 항목의 총 개수입니다.
* *콜드 데이터*: 콜드 데이터 임계값(기본값: 1년) 내에 액세스되지 않은 스토리지입니다. 조직은 보존 및 관리 정책에 따라 이 데이터를 평가할 수 있습니다.
* *오래된 데이터*: 오래된 데이터 임계값(기본값: 3년) 내에 변경되지 않은 스토리지입니다. 오래된 데이터는 아카이브 또는 삭제 등 조치를 결정하기 전에 조직의 데이터 라이프사이클 정책에 따라 검토해야 할 수 있습니다.
* *노출된 디렉터리*: 접근 권한이 지나치게 허용된 디렉터리의 수와 해당 디렉터리에 있는 파일 수입니다. 이는 스토리지 사용량과는 별개로 거버넌스 위험을 나타냅니다.


콜드 및 비활성 임계값은 사용자가 선택한 타임스탬프 및 기간을 포함하여 구성된 설정을 반영합니다. 기본값은 제품 기본값이며 법적, 규정 준수 또는 업계 표준 보존 기간을 나타내지 않습니다. 이를 변경하려면 link:../administer/configure-settings.html["데이터 분류 임계값 및 액세스 스캐닝을 구성합니다"]을(를) 참조하십시오.

*시스템* 및 *시스템 유형* 필터는 대시보드 범위를 제어합니다. 스토리지 시스템이 필터 목록에 나타나지 않으면 link:../data-sources/connect-data-source.html["데이터 소스 연결"]을 참조하십시오.

*최종 업데이트* 타임스탬프는 대시보드 데이터가 마지막으로 새로 고쳐진 시간을 나타냅니다. 대시보드를 업데이트하려면 *새로 고침*을 선택합니다. 기본 데이터가 최신 상태인지 확인하려면 link:../data-sources/manage-data-sources.html#view-scan-status-and-details["스캔 상태 및 세부 정보 보기"]을(를) 참조하십시오.



[[identify-storage-optimization-opportunities]]
== 스토리지 최적화 기회 파악

가장 많은 스토리지를 확보할 수 있는 위치를 찾으십시오. *스토리지 최적화* 탭에는 다음과 같은 차트와 표가 포함되어 있습니다.

* _활성 대 회수 가능 스토리지_: 스캔된 모든 리소스에서 비활성 및 오래된 데이터 대비 활성 데이터의 비율을 보여줍니다. 비활성, 오래된 또는 중복 데이터의 비율이 높으면 스토리지 최적화 기회가 상당함을 나타낼 수 있습니다.
* _회수 가능한 저장 용량 기준 상위 데이터 리소스_: 가장 많은 회수 가능 용량을 가진 데이터 리소스를 보여줍니다.
* _회수 가능한 저장 공간 기준 상위 사용자_: 데이터 소유자, 회수 가능한 저장 공간 및 파일 수를 보여줍니다.
* _중복 데이터 크기 분포_: 중복 데이터가 크기 범위별로 어떻게 분포되어 있는지 보여줍니다.
* _자산 연령_: 항목을 연령별로 표시합니다. 드롭다운을 사용하여 차트의 타임스탬프 기준을 선택하십시오.
* _가장 많이 사용되는 파일 형식_: 가장 일반적인 파일 형식을 보여줍니다.


요약 패널과 이 차트를 사용하여 스토리지 최적화 기회를 파악하고 우선순위를 정하십시오:

* 전체 용량이 가장 큰 리소스보다는 잠재적으로 복구 가능한 용량이 가장 큰 리소스에 집중하십시오. 활성 데이터가 대부분인 대규모 시스템보다 사용 빈도가 낮거나 오래된 데이터가 많은 소규모 시스템이 평가 대상으로 더 적합할 수 있습니다.
* 개별 파일보다는 콜드 또는 오래된 데이터가 대량으로 집중되어 있는 곳을 찾아보십시오. 하나의 리소스에서 수십 테라바이트에 달하는 데이터가 오래된 데이터 임계값을 충족하는 경우 평가가 필요합니다. 개별 파일은 조치가 필요하지 않을 수도 있습니다.




[[review-access-exposure]]
== 접근 노출 검토

권한 검토를 우선적으로 수행할 디렉터리를 찾으십시오. *액세스 노출* 탭에는 디렉터리 경로와 파일 수를 나열하는 _열린 권한이 있는 디렉터리_ 차트가 표시됩니다. 이러한 디렉터리를 자세히 보려면 link:investigate-directories.html["디렉토리 조사"]을(를) 참조하십시오. AI Data Engine이 권한을 검사할지 여부를 제어하려면 link:../administer/configure-settings.html["데이터 분류 임계값 및 액세스 스캐닝을 구성합니다"]을(를) 참조하십시오.



[[explore-structured-data]]
== 정형 데이터 탐색

스캔한 데이터에 어떤 스키마와 테이블이 포함되어 있는지 확인하고 행 수를 비교해 보십시오. *정형 데이터* 탭에는 스키마, 데이터베이스 테이블 이름, 행 수를 나열하는 _정형 데이터 요약_ 테이블이 표시됩니다. 이 데이터를 검색하고 필터링하려면 link:investigate-structured.html["정형 데이터 조사"]을(를) 참조하십시오.



[[move-from-the-dashboard-to-investigation]]
== 대시보드에서 조사 화면으로 이동

조사할 가치가 있는 리소스 또는 소유자를 확인했으면 *스토리지 최적화* 탭의 표를 사용하여 세부 정보로 바로 이동하십시오.

_복구 가능한 스토리지 기준 상위 데이터 리소스_ 표는 스캔한 스토리지 리소스를 중복 데이터 비율 또는 조직의 콜드 및 오래된 데이터 임계값을 충족하는 데이터 비율에 따라 순위별로 나열합니다. 행을 선택하면 해당 리소스로 필터링된 조사 보기가 열립니다. 여기에서 link:investigate-unstructured.html["비정형"] 탭을 사용하여 콜드 또는 오래된 파일을 식별하거나 link:investigate-directories.html["디렉토리"] 탭을 사용하여 권한 노출을 감사할 수 있습니다.

_회수 가능한 저장 공간 기준 상위 소비자_ 표는 잠재적으로 회수 가능한 데이터를 보유한 데이터 소유자를 보여줍니다. 행을 선택하면 해당 소유자의 파일로 필터링된 link:investigate-unstructured.html["조사"] 보기가 열립니다. 여기에서 결과를 검토하고, 조치를 취하거나, 정책으로 저장할 수 있습니다.

대시보드를 검토해도 데이터가 보관 또는 삭제되거나 디렉터리 권한이 변경되지 않습니다.
