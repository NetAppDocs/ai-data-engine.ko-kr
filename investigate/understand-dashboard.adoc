= AI Data Engine 대시보드로 스토리지 상태 평가
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
조사 대상을 결정하기 전에 스토리지 상태를 파악해야 합니다. 조직의 콜드 데이터 및 오래된 데이터 분류 기준에 부합하는 스토리지 용량이 얼마나 되는지, 그리고 이러한 범주에 속하는 데이터를 가장 많이 보유하고 있는 시스템이나 담당자는 누구인지 알아야 합니다. 예를 들어, 용량 부족 경고에 대응하는 스토리지 관리자는 스캔한 스토리지의 상당 부분이 콜드 데이터임을 확인한 후 가장 큰 영향을 미치는 시스템으로 이동하여 즉시 조사를 시작할 수 있습니다.

NetApp Console에서 *AI 데이터 허브* > *AI Data Engine UI*를 선택합니다. 대시보드가 기본적으로 열립니다.



[[understand-how-much-storage-is-affected]]
== 영향을 받는 스토리지 용량 파악

요약 패널은 스캔한 환경 전체에서 문제의 규모를 보여줍니다.

* *콜드 데이터*: 콜드 데이터 임계값(기본값: 1년) 내에 액세스되지 않은 스토리지입니다. 조직은 보존 및 관리 정책에 따라 이 데이터를 평가할 수 있습니다.
* *오래된 데이터*: 오래된 데이터 임계값(기본값: 3년) 내에 액세스 또는 수정되지 않은 스토리지입니다. 오래된 데이터는 보관 또는 삭제 등의 조치를 결정하기 전에 조직의 데이터 라이프사이클 정책에 따라 검토가 필요할 수 있습니다.
* *노출된 디렉터리*: 접근 권한이 지나치게 관대한 디렉터리입니다. 이러한 디렉터리는 저장 공간 사용량과는 별개로 거버넌스 위험을 나타냅니다.
* *데이터 리소스*: 현재 스캔 중인 볼륨, 공유 및 버킷의 개수입니다.
* *총 스캔 파일 수*: 스캔된 모든 데이터 리소스에서 색인화된 파일의 총 개수입니다.


콜드 및 오래된 데이터 임계값은 구성된 설정을 반영하며 *구성* > *설정*에서 변경할 수 있습니다. 기본값은 제품 기본값이며 법률, 규정 준수 또는 업계 표준 보존 기간을 나타내지 않습니다. 자세한 내용은 link:../administer/configure-settings.html["콜드 및 오래된 데이터 임계값 구성"]을 참조하십시오.

_활성 데이터 대 회수 가능 스토리지_ 차트는 스캔된 모든 리소스에서 활성 데이터와 비활성 및 오래된 데이터의 비율을 보여줍니다. 비활성, 오래된 또는 중복 데이터의 비율이 높으면 스토리지 최적화 기회가 상당할 수 있습니다.

*시스템* 및 *시스템 유형* 필터는 대시보드 범위를 제어합니다. 스토리지 시스템이 필터 목록에 나타나지 않으면 link:../data-sources/connect-data-source.html["데이터 소스 연결"]을 참조하십시오.



[[identify-storage-optimization-opportunities]]
== 스토리지 최적화 기회 파악

요약 패널과 차트를 사용하여 스토리지 최적화 기회를 파악하고 우선순위를 정하십시오.

* 전체 용량이 가장 큰 리소스보다는 잠재적으로 복구 가능한 용량이 가장 큰 리소스에 집중하십시오. 활성 데이터가 대부분인 대규모 시스템보다 사용 빈도가 낮거나 오래된 데이터가 많은 소규모 시스템이 평가 대상으로 더 적합할 수 있습니다.
* 개별 파일보다는 콜드 데이터 또는 오래된 데이터가 대량으로 집중된 곳을 찾아보십시오. 하나의 리소스에서 수십 테라바이트에 달하는 데이터가 설정된 기준치를 충족한다면 평가가 필요하지만, 개별 파일은 조치가 필요하지 않을 수도 있습니다.




[[move-from-the-dashboard-to-investigation]]
== 대시보드에서 조사 화면으로 이동

조사할 가치가 있는 리소스 또는 소유자를 확인한 경우 대시보드 하단의 표를 사용하여 세부 정보로 바로 이동할 수 있습니다.

_복구 가능한 스토리지 기준 상위 데이터 리소스_ 표는 스캔한 스토리지 리소스를 중복 데이터 비율 또는 조직의 콜드 및 오래된 데이터 임계값을 충족하는 데이터 비율에 따라 순위별로 나열합니다. 행을 선택하면 해당 리소스로 필터링된 조사 보기가 열립니다. 여기에서 link:investigate-unstructured.html["비정형"] 탭을 사용하여 콜드 또는 오래된 파일을 식별하거나 link:investigate-directories.html["디렉토리"] 탭을 사용하여 권한 노출을 감사할 수 있습니다.

_회수 가능한 저장 공간 기준 상위 데이터 소유자_ 표는 잠재적으로 회수 가능한 데이터를 소유한 데이터 소유자를 보여줍니다. 행을 선택하면 link:investigate-unstructured.html["조사"] 해당 소유자의 파일로 필터링된 보기가 열립니다. 여기에서 결과를 검토하고, 조치를 취하거나, 정책으로 저장할 수 있습니다.
