= AI Data Engine 관리형 AI 액세스 설정을 유지 관리하십시오
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AI Data Engine(AIDE)에서 관리되는 AI 액세스가 요구 사항에 부합하도록 유지하려면 모델 컨텍스트 프로토콜(MCP) 컬렉션, ID 공급자, 액세스 범위 및 서버 설정을 검토 및 업데이트하고 AI 클라이언트의 액세스를 검증하십시오.



[[before-you-begin]]
== 시작하기 전에

* MCP 컬렉션을 구성하고 AI 클라이언트를 연결했습니다. link:quick-start-mcp.html["AI Data Engine을 통한 관리되는 AI 액세스 빠른 시작"]을(를) 참조하십시오.
* 귀하는 *AI Data Engine 관리자* 역할을 가지고 있습니다.


변경 사항은 즉시 적용되지 않습니다. Microsoft Entra ID 앱 역할 또는 범위를 변경하면 사용자는 AI 클라이언트가 새 액세스 토큰을 받은 후에야 업데이트된 액세스 권한을 얻게 되며, 이 과정은 최대 약 1시간이 소요될 수 있습니다. 사용자는 다시 로그인하여 더 빨리 새 토큰을 받을 수 있습니다. 컬렉션에 데이터를 추가하면 AI Data Engine이 파일을 스캔하고 색인을 생성한 후에야 파일을 검색할 수 있게 됩니다.



[[review-mcp-server-and-collection-status]]
== MCP 서버 및 컬렉션 상태 검토

MCP 서버 및 AI 클라이언트가 사용하는 컬렉션의 상태를 검토하고 구성 경고가 있으면 해결하십시오.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *MCP 컬렉션*으로 이동합니다.
. MCP 서버 상태를 검토하십시오:
+
** *실행 중*: MCP 서버가 실행 중입니다. *MCP 연결 활성화*가 켜져 있으면 AI 클라이언트가 연결할 수 있습니다.
** *상태 저하*: MCP 서버는 실행 중이지만, 구성된 ID 공급자가 없거나 메타데이터 카탈로그의 응답이 느린 등 필수 구성 요소가 누락되었거나 비정상입니다. AI 클라이언트가 인증을 수행하거나 컬렉션을 검색하지 못할 수 있습니다.
** *오프라인*: MCP 서버가 중지되었거나, 비활성화되었거나, 연결할 수 없습니다. AI 클라이언트가 연결할 수 없습니다. MCP에 대한 연결이 꺼져 있는 경우 <<enable-or-disable-the-connection-to-mcp,MCP와의 연결 활성화 또는 비활성화>>을(를) 참조하십시오.


. 컬렉션 목록에서 AI 클라이언트가 사용하는 각 컬렉션의 상태를 확인하십시오. 상태가 *활성화됨*인 컬렉션은 AI 클라이언트에서 사용할 수 있습니다. 컬렉션의 볼륨이 아직 스캔 중인 경우, 새 파일을 검색하기 전에 인덱싱이 완료될 때까지 기다리십시오.
. 구성 경고를 해결하십시오:
+
** ID 공급자가 누락된 경우 *구성* > *ID 공급자*에서 추가하십시오. link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["ID 공급자를 설정하십시오"]을(를) 참조하십시오. ID 공급자의 *연결 상태*가 *연결됨*인지 확인하십시오.
** 컬렉션에 *구성 준비됨*이 표시되면 해당 컬렉션의 *작업* 메뉴를 열고 *MCP용 구성*을 선택한 다음 ID 공급자와 사용자 범위를 선택합니다. link:manage-data-collections.html#configure-a-collection-for-mcp["MCP용 컬렉션 구성"]을(를) 참조하십시오.
** 컬렉션의 볼륨에 스캔 오류가 표시되면 link:../data-sources/manage-data-sources.html#view-scan-status-and-details["스캔 상태 및 세부 정보 보기"]을(를) 참조하십시오.






[[edit-a-data-collection]]
== 데이터 수집 편집

MCP 컬렉션의 이름, 설명 또는 데이터 리소스를 업데이트합니다.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *MCP 컬렉션*으로 이동합니다.
. 컬렉션의 *작업* 메뉴를 열고 *편집*을 선택하십시오.
. 필요에 따라 이름이나 설명을 업데이트하십시오.
. 데이터 리소스를 선택하거나 선택 해제하여 컬렉션을 업데이트하십시오.
. *MCP 컬렉션 저장*을 선택하십시오.


*모든 파일* 컬렉션은 편집, 이름 변경 또는 삭제할 수 없습니다. MCP에 맞게 구성할 수 있습니다. <<update-identity-providers-or-user-scopes-for-a-collection,컬렉션에 대한 ID 공급자 또는 사용자 범위를 업데이트합니다>>을(를) 참조하십시오.



[[update-an-identity-provider]]
== ID 공급자 업데이트

공급자 구성이 변경될 때 ID 공급자를 업데이트하십시오.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *ID 공급자*로 이동합니다.
. ID 공급자를 편집 모드로 엽니다.
. 필요에 따라 테넌트 ID, 애플리케이션(클라이언트) ID 또는 이름을 업데이트하십시오.
. *저장*을 선택합니다.


관리자 액세스가 필요한 경우 관리자에게 ID 공급자를 업데이트해 달라고 요청하십시오.



[[update-the-identity-providers-or-user-scopes-for-a-collection]]
[[update-identity-providers-or-user-scopes-for-a-collection]]
== 컬렉션에 대한 ID 공급자 또는 사용자 범위를 업데이트합니다

컬렉션에 대한 액세스 권한을 부여하는 ID 공급자 또는 포함하는 사용자 범위를 변경한 다음 업데이트된 연결 세부 정보를 복사합니다.

.시작하기 전에
필요한 ID 공급자가 목록에 없으면 먼저 *ID 공급자*에서 연결하십시오. link:connect-entra-id-aide-mcp.html#set-up-an-identity-provider["ID 공급자를 설정하십시오"]을(를) 참조하십시오.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *MCP 컬렉션*으로 이동합니다.
. 컬렉션의 *작업* 메뉴를 열고 *MCP용으로 구성*을 선택합니다.
. 컬렉션에 대한 접근 권한을 부여할 ID 제공업체를 선택하십시오.
. 선택한 각 ID 공급자에 대해 *포함할 사용자 범위*를 검토하십시오. *모든 사용자 범위*를 유지하거나 특정 범위를 선택한 후 *범위 추가*를 선택하십시오.
. *MCP 코드 스니펫 생성*을 선택하세요.
. 업데이트된 *MCP 서버 URL* 또는 AI 클라이언트용 구성 스니펫을 복사한 다음 *닫기*를 선택하십시오.


.결과
이 컬렉션은 선택한 ID 공급자 및 사용자 범위를 사용합니다. MCP 서버 URL 또는 구성 스니펫이 변경된 경우 영향을 받는 각 AI 클라이언트를 업데이트하십시오. <<update-ai-client-connections-and-validate-access,AI 클라이언트 연결을 업데이트하고 액세스 권한을 확인합니다>>을(를) 참조하십시오.

이 작업에 대한 자세한 내용은 link:manage-data-collections.html#configure-a-collection-for-mcp["MCP용 컬렉션 구성"]을(를) 참조하십시오.



[[enable-or-disable-the-connection-to-mcp]]
== MCP와의 연결 활성화 또는 비활성화

AI 클라이언트가 MCP 컬렉션에 연결할 수 있도록 하려면 *MCP 연결 활성화*를 켜십시오. 이 연결은 기본적으로 비활성화되어 있습니다. MCP 서버 설정 후 AI 클라이언트용 MCP 코드 스니펫을 생성하기 전에 이 옵션을 켜십시오. 나중에 이 옵션을 끄면 다시 켤 때까지 AI 클라이언트의 연결이 차단된 상태로 유지됩니다.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *MCP 컬렉션*으로 이동합니다.
. *MCP 설정*을 선택합니다.
. *MCP 서버 연결*을 확장합니다.
. *MCP 연결 활성화* 토글을 사용하여 연결을 켜거나 끄십시오.
+

CAUTION: MCP 서버 연결을 비활성화하면 컬렉션 설정과 관계없이 모든 MCP 컬렉션에 대한 AI 클라이언트의 모든 요청이 차단됩니다. 이미 연결된 AI 클라이언트는 다음 요청 시 액세스 권한을 잃게 됩니다. 서버 전체에 대한 액세스를 일시적으로 중단하려는 경우에만 연결을 비활성화하십시오.

. 연결을 활성화한 후 MCP 서버의 상태가 *실행 중*인지 확인하십시오. <<review-mcp-server-and-collection-status,MCP 서버 및 컬렉션 상태 검토>>을(를) 참조하십시오.




[[review-mcp-server-settings]]
== MCP 서버 설정을 검토하십시오

AI 클라이언트가 MCP 서버에 연결할 수 있는지 검토하고 AIDE 클러스터 호스트 이름을 검토하십시오.

.단계
. NetApp Console에서 *AI 데이터 허브* > *AI Data Engine* > *구성* > *MCP 컬렉션*으로 이동합니다.
. *MCP 설정*을 선택합니다.
. *MCP 서버 연결* 항목에서 *MCP 연결 활성화*를 검토하십시오. 연결을 켜거나 끄려면 <<enable-or-disable-the-connection-to-mcp,MCP와의 연결 활성화 또는 비활성화>>을(를) 참조하십시오.
. *MCP 호스트 이름* 항목에서 AIDE 클러스터 호스트 이름을 검토하십시오. 변경해야 하는 경우 업데이트된 호스트 이름을 입력하고 *구성*을 선택하십시오.
+

CAUTION: AIDE 클러스터 호스트 이름을 변경하면 MCP 서버 URL이 변경됩니다. 이전 URL을 사용하는 AI 클라이언트는 연결 설정을 업데이트하기 전까지 연결할 수 없습니다. 새 호스트 이름은 Entra ID 테넌트에서 확인된 도메인에 있어야 합니다. Application ID URI와 범위는 호스트 이름에서 생성되므로 Entra ID에서도 이를 업데이트해야 합니다. <<update-ai-client-connections-and-validate-access,AI 클라이언트 연결을 업데이트하고 액세스 권한을 확인합니다>>을(를) 참조하십시오.

+

NOTE: HTTPS로 MCP 서버를 보호하려면 SSL/TLS 인증서가 필요합니다. NetApp Console은 인증서를 관리하지 않습니다. 인그레스 스크립트는 인증서와 AIDE 클러스터 호스트 이름을 설정합니다. 호스트 이름은 Entra ID 테넌트에서 확인된 도메인에 있어야 합니다. link:prepare-mcp-host.html["MCP 호스트를 준비합니다"]을(를) 참조하십시오.

. *닫기*를 선택합니다.




[[update-ai-client-connections-and-validate-access]]
== AI 클라이언트 연결을 업데이트하고 액세스 권한을 확인합니다

컬렉션, ID 공급자, 사용자 범위 또는 서버 설정을 변경한 후에는 AI 클라이언트가 여전히 연결할 수 있는지, 그리고 액세스 권한이 의도한 권한과 일치하는지 확인하십시오.

.단계
. MCP 서버 URL 또는 생성된 구성 스니펫이 변경된 경우, 영향을 받는 각 AI 클라이언트에서 연결 설정을 업데이트하십시오. link:connect-ai-clients-mcp.html["AI 클라이언트 연결"]을(를) 참조하십시오.
. 영향을 받는 각 AI 클라이언트에서 클라이언트가 연결 및 인증될 수 있는지 확인하십시오.
. 대표 검색 요청을 실행하세요.
. 예상되는 컬렉션 콘텐츠에 접근 가능한지, 그리고 접근 권한이 의도된 권한과 일치하는지 확인하십시오.


.결과
MCP 설정에 변경 사항이 반영되었고, 영향을 받는 AI 클라이언트가 연결할 수 있으며, 액세스 권한이 의도한 대로 일치합니다.
